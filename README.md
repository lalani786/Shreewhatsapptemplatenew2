# Shree AI Messenger

Next-Generation WhatsApp Automation, AI Video Production & Multi-Channel Social Marketing Suite.

## Features

- **WhatsApp Cloud API Integration**: Automated broadcasts, custom Meta message templates, and interactive quick replies.
- **AI Marketing Video Studio**: Automated video creation with Ken Burns effects, NVIDIA Cosmos, Pexels video clips, and synchronized ElevenLabs neural voiceovers + background music.
- **AI Image Generation**: Multi-provider HD generation supporting NVIDIA NIM (FLUX Commercial HD) and Pollinations.ai.
- **Multi-Channel Social Media Sync**: Auto-publish updates and media to Instagram, YouTube, Facebook, and LinkedIn.
- **Photo Studio**: Product photography enhancer with smart background and aspect-ratio adaptation.

## Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, shadcn-ui, Lucide Icons
- **Backend**: Supabase (Database, Auth, Storage, Edge Functions)
- **AI Integrations**: NVIDIA NIM, ElevenLabs, Pollinations.ai, Gemini

## Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```
